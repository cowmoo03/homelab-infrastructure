# Roadmap

This homelab is an ongoing learning environment. Planned additions include:

- Automated VM and application backups
- Centralized logging and SIEM experimentation
- Windows Server and Active Directory
- Additional security-testing VMs
- Vulnerable targets isolated inside the security lab
- Ansible for configuration automation
- Network and service monitoring
- NAS/file-storage expansion
- Local AI-assisted administration with no required cloud dependency
- Improved documentation diagrams and recovery runbooks

The goal is to continue moving from individual services toward a more complete small-enterprise-style environment with repeatable administration, monitoring, backup, and security practices.
